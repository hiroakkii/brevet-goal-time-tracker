# ブルベ ゴールタイム計測

ブルベのゴール受付で、参加者のゴール時刻とタイムを記録するアプリです。
`index.html` の1ファイルだけで動きます。インストールやサーバーは必要ありません。

## 使える端末

- パソコンの Chrome / Edge（おすすめ）
- スマホ（横向きがおすすめ。縦向きでも横にはみ出さずに使えます）

記録は、開いた端末のブラウザの中に保存されます。インターネット上には送られません。

## 開き方

1. `index.html` をダウンロードします。
2. ダウンロードしたファイルを Chrome または Edge で開きます。

名簿の取り込み・Excel書き出し用の部品と文字の書体をインターネットから読み込むため、
最初に開くときは通信できる状態で開いてください。

## 大会当日の流れ

1. **設定**タブでスタート時刻（全員共通）を保存します。
2. 名簿があれば、**設定**タブで出場者名簿（Excel / CSV）を取り込みます。名簿がなくても受付番号だけで計測できます。
3. **記録**タブで、ゴールした人の受付番号を入れて「ゴール記録」を押します（Enter キーでも記録できます）。
   - 何人も同時に着いたときは「時刻だけ打刻」で時刻を先に残し、受付番号はあとから入れます。
   - 未出走は「DNS」、途中棄権は「DNF」で記録します。
   - 右側の「直近の記録」で、最新8件の確認・メダルの有無の入力・編集ができます。
4. 終わったら**一覧**タブで結果を確認し、Excel または CSV で書き出します。

## 画面ごとの機能

### 画面上部
- 左上にクラブのロゴ（Randonneurs MIYAGI）と大会名を表示します。
- 一覧タブでは、ロゴを一覧の見出し（リザルト）に大きく表示するため、上部は大会名だけになります。

### 記録
- スタートからの経過時間を大きく表示します。24時間を超えてもそのまま数えます。
- 「ゴール記録」を押すと、お知らせ欄に「宮城」の判子がポンと押され、名前とタイムが出ます。
  判子が出るのはゴール記録のときだけです（DNS・DNF・時刻だけ打刻では出ません）。
  端末で「動きを減らす」設定にしている場合は、動かさずに判子だけ表示します。
- 同じ受付番号を2回記録しようとすると止めます。

### 一覧
- 並び順：タイム順（順位つき）／記録が新しい順／受付番号順
- メダルの有無の切り替え、記録の編集・削除、手入力での追加
- 書き出し
  - **Excel**：取り込んだ名簿（.xlsx）のレイアウト・書式のまま、右側に「走行時間／メダル／認定番号」の列を足します。
    名簿のタイトルにある「申込確認リスト」は「リザルト」に置き換えます。認定番号は空欄のままです。
  - **CSV**：順位・受付番号・氏名・結果・ゴール日時・タイム・メダル
- Excel の走行時間は「時:分」か「時:分:秒」を選べます。

### 設定
- スタート時刻：あとから直すと、全員のタイムが計算し直されます。
- 出場者名簿の取り込み
- 自動バックアップ（パソコンの Chrome / Edge のみ）
- バックアップの保存・復元、全データの削除

## 名簿の形式

- 1行目（または上のほうの行）に見出しを入れます。
  - 受付番号の列：「受付番号」「ナンバー」「No」「番号」「ゼッケン」のどれか
  - 氏名の列：「氏名」「名前」「Name」のどれか
- 見出しが見つからないときは、A列を受付番号、B列を氏名として読みます。
- A1 セルに『』で囲んだ大会名があれば、画面上部に大会名として表示します。
- 取り込み直すと名簿は置き換わります。記録済みのタイムは消えません。

## データを失わないために

- 記録はブラウザの中に保存されます。ブラウザの閲覧データを消すと記録も消えます。
- プライベートモード（シークレットウィンドウ）では保存されません。通常のウィンドウで開いてください。
- 大会中は、休憩のたびに**設定 → バックアップを保存**しておくと安心です。
- パソコンなら**自動バックアップ**が便利です。保存先を一度選ぶと、記録するたびにそのファイルへ上書き保存します。
  Dropbox や OneDrive などの同期フォルダに置けば、パソコンが壊れても別の場所に残ります。
  ブラウザを開き直したあとは確認が出るので「再開」を押してください。
- 別の端末に移るときは、バックアップを保存して、新しい端末の「バックアップから復元」で読み込みます。
